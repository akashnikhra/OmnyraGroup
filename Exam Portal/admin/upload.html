CSV format guide
  1. Header row (exact, UTF-8): id,question,optionA,optionB,optionC,optionD,correctIndex,rationale,topic,difficulty,marks — legacy alias option1,option2,option3,option4 is also accepted on upload.
  2. One row per question (max 500 rows + header). Keep the header as row 1; data starts row 2.
  3. Quoting: wrap any field containing a comma, quote, or line-break in "double quotes"; escape a literal quote as "".
  4. correctIndex is 0-based: 0=A, 1=B, 2=C, 3=D.
  5. marks is an integer 1–100; difficulty is easy|medium|hard; question and rationale need ≥ 10 chars; all 4 options must be distinct.
